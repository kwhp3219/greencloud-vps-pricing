## 那些只写在详情页里的限制

绿云的配置表看起来都很大方，但几个细节藏在每个套餐的说明列表里，直接影响体验：

- **CPU 分两代，差很多。** 同样叫 4GB 档促销机，Ashburn、多伦多、洛杉矶是 EPYC Rome + NVMe RAID-10，而芝加哥、杰克逊维尔、堪萨斯城、达拉斯是 Intel E5v4 + SSD RAID-10——E5v4 是 2016 年前后的老架构，单核性能明显弱一截。价格一样的时候，优先挑 EPYC 机房。有 NodeSeek 用户也提过，活动机的宣传 CPU 和实际到手不一定一致，以实测为准。
- **CPU 是 fair-share 限制，超售时会压性能。** 1313 这类套餐的 6 核是 fair-share EPYC Milan，跑持续高负载的应用（采集、转码、挖矿类）容易被限，绿云的 CPU 限制在社区里是出了名的偏严。

- **部分机房带 SWAP 补偿。** 杰克逊维尔、堪萨斯城、达拉斯的套餐额外给 1–4GB SWAP，算是用老 CPU 换来的一点安慰。
- **周年庆活动机全部不退款。** 1313 三年付 $123 覆盖 14 个机房，美加欧给 12TB 流量、日新港给 3333GB，配置确实宽，但买错机房三年都难受，下单前务必用官网测试 IP 页逐个测。
